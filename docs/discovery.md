# Business and technical discovery

- Confirm the precise AVEVA and Aras products, versions and environments.
- Identify business owners, users and the intended exchange scenarios.
- Obtain approved API documentation and authentication requirements.
- Confirm network access, service accounts and required permissions.
- Agree object types, identifiers, attributes, units and revisions.
- Decide exchange direction, triggers, frequency and expected volume.
- Define system of record and conflict resolution for each object type.
- Agree validation, acceptance criteria, audit and retention requirements.
- Obtain representative sanitized samples and a non-production test environment.
